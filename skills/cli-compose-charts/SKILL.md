# Charts

Use charts when values communicate something useful. Choose --hbar-chart or
--vbar-chart with at least two label:value items, --sparkline for a compact
numeric sequence, or --progress for a percentage or fraction. Use
--charset=unicode for Unicode blocks, and set alignment and size explicitly
when needed. See cli-compose-text --help=charts for syntax and output.
