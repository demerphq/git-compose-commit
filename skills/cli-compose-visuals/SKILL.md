# Visual decorations

Use --banner for a short heading, --badges for compact labels, or --stamp for
named artwork when decoration helps the reader. Choose alignment and width
explicitly when reproducibility matters. Unicode is opt-in with
--charset=unicode. See cli-compose-text --help=visuals for syntax and examples.
