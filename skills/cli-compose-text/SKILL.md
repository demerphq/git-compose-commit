# Compose structured text

Use cli-compose-text to build text from arguments for a file, a terminal, or
another tool. It writes to stdout by default; --output FILE writes a file.
Use --help=TOPIC for focused syntax and examples, and choose specialized
cli-compose skills when a table, list, chart, or other feature fits.

When preparing a Git commit, follow the user's instructions and repository
conventions. Use the git-compose-commit skill for the Git-specific workflow;
do not create commits without authorization.
