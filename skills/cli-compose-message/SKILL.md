# Compose the text

Use cli-compose-text when structured text needs prose or details. Put the
heading in --subject, use --text for wrapped paragraphs, --detail for indented
literal text, and --line for an unwrapped line. Fields and callouts can make
related information easier to scan. Review the output before using it.

Run cli-compose-text --help=message for syntax and examples. The same message
options work with git-compose-commit.
