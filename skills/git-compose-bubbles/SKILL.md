# Bubbles

Use a bubble only when the user or project welcomes a whimsical touch.
Pass --bubble 'Hello there!' for a phrase with defaults and random choices,
or specify speaker, style, placement, and phrase clauses. Configure the
choices explicitly when output must be repeatable. Preview before committing.
Speakers include a cow, cat, dog, robot, owl, dragon, penguin, duck, ghost,
and stick figure.
For an optional original joke, --fortune=1 through --fortune=6 selects one;
--fortune=random uses the same seed as bubble choices.
See git-compose-commit --help=bubbles for the full syntax and examples.
