# Tables

Use a table when rows share columns and the comparison helps the reader.
With cli-compose-text, start with --table-head and add --table-row or
--table-rows. Cells use simple delimiters, not CSV quoting. Prefer prose when
a table adds noise. See cli-compose-text --help=tables for examples. The same
options work with git-compose-commit.
