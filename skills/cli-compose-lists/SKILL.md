# Lists

Use lists for steps or related points that are easier to scan separately.
Start a numbered list with --numlist or a bullet list with --bullets; add
items with --list-item and close a nested list with --list-end. For a
checklist, repeat --checklist-item with done:TEXT or todo:TEXT. See
cli-compose-text --help=lists for examples; the Git wrapper accepts these
same options.
