# Footers

Use numbered footers when a detail would interrupt the main explanation.
Reference [#1] in --text or --line and define it with --footer-1. Every
reference needs a definition, and unused definitions are errors. See
cli-compose-text --help=footers for examples. The Git wrapper accepts the
same options.
