# Compose the message

Use when a commit needs prose or structured details. Review the change and
project instructions; put the outcome in the subject, then explain why and
how in short paragraphs. Use --text for wrapped prose, --detail for indented
literal text, and --line for an unwrapped line. Fields and callouts are useful
when they make the information easier to scan. Preview with --stdout.

Run git-compose-commit --help=message for syntax and examples. Do not commit
without authorization.
