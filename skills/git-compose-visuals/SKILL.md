# Visual decorations

Use --banner for a short heading, --badges for compact labels, or --stamp for
named artwork when the
user or repository welcomes decoration. Keep the subject conventional.
Choose alignment and width explicitly if reproducibility matters, and preview
the result. Unicode is opt-in with --charset=unicode. See
git-compose-commit --help=visuals for syntax and examples. The tool formats
text; it does not authorize a commit.
