git-compose-commit - build a message and run git commit

Usage: git-compose-commit [COMPOSE OPTIONS] [GIT OPTIONS] [-- PATHSPEC...]

Create a commit:
  git-compose-commit --subject 'Refresh cache' --text 'Update readers.' --all

Preview without committing:
  git-compose-commit --subject 'Refresh cache' --text 'Update readers.' \
    --stdout

Message:   --subject, --text, --detail, --line, --field, --note, --warning
Structure: --table-head/--table-row, --list-item, --checklist-item, --footer-N
Visuals:   --sparkline, --progress, --banner, --badges, --bubble, --fortune
Charts:    --hbar-chart, --vbar-chart, --hflow-chart, --flow-chart
Control:   --stdout, --output, --wrap-width, --charset, --rand-seed, --version

Use --help or --man for the full guide. Focus with --help=TOPIC:
  message, output, tables, lists, footers, charts, flowcharts, visuals,
  bubbles, examples
Agent skills: --agent-usage-list-skills and --agent-usage-show-skill=NAME
